Conectar os dados reais

O painel funciona em modo demonstração até receber dados reais. Os filtros 7, 15, 30, 60, 90, 180, 365 dias, Tudo e Datas mostram apenas o histórico efetivamente disponível; o histórico completo não cria vendas retroativas. O site não utiliza robôs para extrair informações de serviços que não autorizaram coleta automatizada.

Usar agora

Clique em Importar arquivo no painel. Aceita CSV de vendas (timestamp,item,price,quantity,type,category), CSV OHLCV (timestamp,item,open,high,low,close,volume,trades,category) ou JSON com candles.

Atualização automática

Publicando no GitHub Pages com o diretório docs/ e configurando os segredos MARKET_FEED_URL e, se necessário, MARKET_FEED_TOKEN, a rotina GitHub Actions consulta seu feed autorizado a cada hora, valida dados e atualiza os candles. O agendamento do GitHub pode sofrer atrasos.

Veja o arquivo README.md do pacote para o passo a passo completo e os schemas aceitos.

Sobre os candles

Os candles de verdade precisam de preços de negócios realizados, com data/hora. Uma mediana diária ou um preço pedido não é um negócio, e não pode ser apresentado como OHLCV de transações.
